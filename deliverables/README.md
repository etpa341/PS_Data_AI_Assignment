# Deliverables

The final files a reviewer needs first, in one folder. Start with `report.pdf` (or `report.md`).

These are copies generated by `make_deliverables.py`. The source of each is the file named beside it.

Paths in backticks in `report.md` and `appendix.md` (for example `outputs/q2_robustness.csv`) are paths in the repo, not in this folder; only the files listed below are copied here.
